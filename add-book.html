One-time setup: GitHub token

This lets the form save to your site. It is stored only in this browser, never on the site. Use your own phone or computer.

  1. Open GitHub's new token page.
  2. Name it "BookNook form" and pick an expiry date (90 days or longer).
  3. Under Repository access, choose Only select repositories and pick BookNook-.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Click Generate token, copy it, and paste it below.
Manual way (if you prefer)
  1. Click Copy list below.
  2. Click Open book list on GitHub, select everything in the editor, and paste.
  3. Click Commit changes. Your site updates in about a minute.
